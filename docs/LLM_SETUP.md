# 接入真实 AI 大模型 · 配置指引

> 本项目的「AI 用药助手」已经支持接入真实大模型。  
> **不配置也能正常用**：没有 API Key 时，问答会自动回退到内置规则引擎，功能完整、演示不翻车。  
> 下文说明如何获取 Key 并启用大模型。

---

## 一、推荐用哪家（当前默认：阿里通义千问）

| 对比项    | 通义千问 Qwen（推荐） | DeepSeek | OpenAI GPT |
| ------ | ------------- | -------- | ---------- |
| 国内直连   | ✅ 无需科学上网      | ✅ 无需科学上网 | ❌ 需要代理     |
| 免费额度   | ✅ 新用户送 token  | ✅ 有      | 仅新用户少量     |
| 中文医疗场景 | ✅ 好           | ✅ 好      | ✅ 好        |
| 申请难度   | 简单            | 简单       | 需海外手机号/信用卡 |

默认已配好通义千问；想换 DeepSeek 只需改 `.env` 里两行（见第五节）。

---

## 二、申请阿里云百炼 API Key（约 5 分钟）

1. 打开 **阿里云百炼控制台**：<https://bailian.console.aliyun.com/>
2. 用支付宝扫码 / 手机号注册登录（个人即可，无需企业认证）。
3. 首次进入会提示开通「模型服务」，点同意、领取新用户免费额度（一般送几十万 token，演示绰绰有余）。
4. 左侧菜单找到 **「API-KEY」**（或右上角头像 → API-KEY 管理）。
5. 点 **「创建 API-KEY」**，复制生成的那串 `sk-xxxxxxxx`。

> ⚠️ Key 只会完整显示一次，请立刻粘贴保存。泄露了要立即删除重建。



---

## 三、把 Key 填进项目

打开项目根目录的 `.env` 文件，找到这一段：

```ini
LLM_API_KEY=
```

把 Key 填到等号后面（不要加引号、不要有空格）：

```ini
LLM_API_KEY=sk-在此填入密钥
```

保存后**重启服务**（关闭进程后重新执行 `npm start`），配置即生效。

---

## 四、验证是否接上真模型

启动后，打开子女端 → 「AI 用药助手」→ 问一句：

> 「阿司匹林和布洛芬能一起吃吗？」

- **接上真模型**：回答是自然流畅、结合该家庭数据的完整句子，回答末尾会显示来源 `qwen-plus`。
- **没接上（回退规则）**：回答是固定的通用话术，来源显示「通用用药安全规范」。

也可以看服务日志：如果打印了 `[assistant] 大模型调用失败，回退规则引擎`，说明 Key 没填对或网络不通。

## 五、换成其他模型（可选）

`.env` 里改两行即可，代码不用动：

**换成 DeepSeek：**

```ini
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

**换成 Moonshot Kimi：**

```ini
LLM_BASE_URL=https://api.moonshot.cn/v1
LLM_MODEL=moonshot-v1-8k
```

**通义千问内换更便宜/更强的型号：**

```ini
LLM_MODEL=qwen-turbo    # 更快更便宜，适合高频问答
LLM_MODEL=qwen-max      # 更强，成本略高
```

---

## 六、几个关键设计（答辩可讲）

1. **可插拔**：走 OpenAI 兼容协议，换任何一家只改 `.env`，业务代码零改动。
2. **自动降级**：没 Key、断网、额度耗尽时自动回退规则引擎，功能永远可用。
3. **主动建议仍是规则引擎**：`buildInsights` 产出的是可追溯的结构化建议（每条带 evidence 证据），不交给大模型，保证稳定、可测试、有依据。
4. **大模型只用于「问答」**：这正是它真正的价值——理解自然语言、结合家庭服药背景自由对话。
5. **零新增依赖**：用 Node 原生 `fetch` 直连，不装 SDK。

---

## 七、安全提醒

- `LLM_API_KEY` 只写在本地 `.env`，**切勿提交到公开仓库**（项目已 `.gitignore` 掉 `.env`）。
- 不要把 Key 写进前端代码或方案书里。
- 演示后若担心泄露，可在百炼控制台删除重建 Key。
